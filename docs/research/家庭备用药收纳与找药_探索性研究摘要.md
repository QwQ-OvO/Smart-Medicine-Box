# 家庭备用药收纳与找药：探索性研究摘要

本页为对外提交摘要，替代包含个人用药经历的内部访谈逐字稿。研究基于一名参与者的文字交流和自述，没有现场观察、独立样本或实际行为测试。

## 与产品有关的观察

- 低频使用的常备药可能分散存放，查找依赖记忆和逐处翻找。
- 参与者表达了对逐次更新存取记录的低意愿；这是自报意愿，尚未通过行为验证。
- 无法确认药品去向时，不能直接推断已用完、重复购买或库存缺失。

## 形成的设计判断

聚焦“为已知药品提供历史位置线索”，在整理或实际找到时记录，保留时间与来源；线索失效后允许反馈并补充新位置。不要求每次取用登记，不承诺实时库存。

## 证据边界与下一步

单人探索不能证明普遍需求、查找效率改善或减少浪费。下一步观察目标用户独立完成记录、查找和纠正任务，并验证低频记录的收益是否超过维护成本。AI 输入方式也需与手工填写比较总耗时和纠错成本。
